# 旅行规划助手

一个静态旅行规划网页，提供旅行偏好设置、路线规划和旅行建议等功能。

## 在线访问

https://siyan-travel-assistant.netlify.app/

## 使用方式

1. 打开上方网站。
2. 设置旅行偏好和本次出行需求。
3. 生成并查看旅行规划方案。

## 部署设置

- Production branch：`main`
- Build command：留空
- Publish directory：`.`

## 技术说明

项目使用 HTML、CSS 和 JavaScript，通过 GitHub 管理版本，并由 Netlify 自动部署。
